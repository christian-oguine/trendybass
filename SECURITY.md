# Security policy

Trendybass is built with a Secure Software Development Lifecycle (see [docs/ssdlc.md](docs/ssdlc.md)). We take reports seriously.

## Reporting a vulnerability

- Use GitHub's **private vulnerability reporting** (Security tab → "Report a vulnerability"), or email **security@trendybass.com** (address being set up).
- Do not open a public issue for security problems.
- Please include the steps to reproduce, the affected page or API, and the impact.

## What to expect

- We confirm receipt within 3 working days.
- We share our assessment and a planned fix date within 10 working days.
- We credit reporters who want to be named, once the fix is live.

## Rules for testing

- Only test with accounts you own. Never access, change or delete other people's data or orders.
- No real payments with cards that are not yours. Use Stripe test mode details where offered.
- No denial-of-service, spam, social engineering or physical attacks.
- Stop and report as soon as you see personal data or photos of other people.

## Supported versions

Only the latest version running on trendybass.com is supported.
